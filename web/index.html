    Settings

    Preferences below are stored on the EvuProxy host as ui-preferences.json next to the main config (not in WireGuard YAML). The API token is on the sidebar page “API token” and stays in the browser only.

    Peer tunnel subnet

    IPv4 CIDR used to pick the next free tunnel IP when you add a peer. Should match the WireGuard tunnel network. Server default is 10.100.0.0/24 when unset.

    WireGuard server endpoint

    Public address peers use to reach this VPN (host:port or hostname:port). Pre-filled in the peer form; port can be omitted if it matches the server listen port after you refresh server details.

    Public interface

    Linux NIC that faces the Internet (e.g. eth0, ens18). Written to config.yaml for nftables and NAT — reload firewall rules after changing.

    Collect peer ICMP metrics on the host (evuproxy metrics systemd service). Enables the Ping column on Peers; overview latency cards always load from stored metrics. Requires ping on the server.

    Operator notes

    Plain text on the host as config-notes.txt next to config.yaml. Not part of WireGuard YAML.

    Backup & restore

    Archives live under the backup allow directory (default /var/backups); paths are validated by the API ( EVUPROXY_BACKUP_DIR).

    Replace config (upload)

    Preview JSON before saving to the server. The saved config replaces what is on disk; YAML comments from the uploaded file are not preserved.

    Advanced settings

    Shows the Advanced tab on Routes and Geoblocking (rate limits, port maps, break-glass, etc.). When off, that tab is visible but disabled with a link here. Stored only in this browser (localStorage).

    Advanced mode

    Max width of the main panel. Stored only in this browser (localStorage).

    Diagnostics

    Raw status from the host (WireGuard + nftables table).

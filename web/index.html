Overview

Host, tunnel and geo state at a glance, plus the two host actions that do not need a config change.

Apply

Maintenance mode

When on, public forwards are omitted until you turn this off and reload.

Recent activity

From the host state/events.jsonl (append-only, size-capped). Polls while you stay on Overview.

    No events recorded yet.

    Settings

    Admin UI preferences, operator notes and backups. Stored on the host, not in WireGuard YAML.

    IPv4 CIDR used to pick the next free tunnel IP for a new peer. Defaults to 10.100.0.0/24.

    Public host:port peers dial to reach this VPN. Pre-filled in the peer form.

    Linux NIC facing the Internet, e.g. eth0. Reload firewall rules after changing.

    Collect peer ICMP metrics

    Runs the evuproxy metrics service on the host and enables the Ping column on Peers.

    Operator notes

    Plain text on the host as config-notes.txt next to config.yaml. Not part of WireGuard YAML.

    Backup & restore

    Archives live under the backup allow directory (default /var/backups); paths are validated by the API ( EVUPROXY_BACKUP_DIR).

    Replace config (upload)

    Preview JSON before saving to the server. The saved config replaces what is on disk; YAML comments from the uploaded file are not preserved.

    Advanced settings

    Shows the Advanced tab on Routes and Geoblocking (rate limits, port maps, break-glass, etc.). When off, that tab is visible but disabled with a link here. Stored only in this browser (localStorage).

    Advanced mode

    Max width of the main panel. Stored only in this browser (localStorage).

    Diagnostics

    Host status preview, or download a Markdown support bundle (WG, routes, logs, networkd).
